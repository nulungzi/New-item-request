# 신규 자재 소요제기 · 구매이력 검색

품번/품명/규격으로 검색하면 **어느 구매처에서 많이 샀는지**, **MFG(제조사)는 어디인지**를 한눈에 보여주는 웹 페이지입니다.
핸드폰·PC 브라우저 어디서든 `index.html`을 열면 동작합니다 (GitHub Pages로 배포 가능).

## 사용법
1. `index.html` 열기 → 샘플 데이터(`data/sample.csv`)가 자동 로드됨
2. "구매이력 파일 불러오기"로 실제 CSV/XLSX 선택 (파일은 브라우저 안에서만 처리, 서버 전송 없음)
3. 검색창에 품번·품명·규격 입력 (띄어쓰기로 여러 단어 AND 검색)

## 인식하는 열 이름
품번 / 품명 / 규격 / 구매처(업체, 공급사) / 제조사(MFG, Maker) / 수량 / 단가 / 구매일
